# Ficha 02 — Módulo de catálogo

Catálogo de oito produtos de tecnologia e acessórios, com categorias, pesquisas e descontos.

## Ficheiros

- `data.js` — os produtos do catálogo.
- `catalog.js` — as seis funções puras para trabalhar com os produtos.
- `app.js` — lê os argumentos da linha de comandos e mostra os resultados.
- `check.js` — testes às seis funções.
- `report.json` — relatório criado com `node app.js report`.

## Comandos

Executar dentro da pasta `twa-ficha02`:

```bash
node app.js
node app.js tech
node app.js search gaming
node app.js top 3
node app.js report
node check.js
```

`node check.js` não apresenta mensagens quando os testes passam.
